An entry for [One Word for Your Wi-Fi](https://make.fun/bounty/u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72) on make.fun: one word that describes your Wi-Fi, aiming to be both the funniest and the most accurate.

## The word

> Ghosting

Home Wi-Fi behaves like a bad date: full bars, all smiles — then, mid-call, mid-download, it vanishes without a word and leaves you staring at a spinning wheel.

## How it works

`main.py` writes the word (one word, 8 letters) to `/output/entry.txt`. The program uses only the Python standard library, validates the word against the competition gate (1–20 characters, exactly one word, not only whitespace), and produces byte-identical output on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
